# Ostrowski's Theorem: The Duality of Absolute Values on $\mathbb{Q}$

## 1. Introduction

Ostrowski's theorem (1916) is one of the most elegant and consequential results in number theory. It states that every nontrivial absolute value on the rational numbers $\mathbb{Q}$ is equivalent to either the standard real absolute value $|\cdot|$ or a $p$-adic absolute value $|\cdot|_p$ for some prime $p$. In more direct language: **there are exactly two kinds of metrics you can put on the rational numbers.**

For the metric-neutrality project, Ostrowski's theorem provides the mathematical foundation. It proves that metric neutrality is not merely a philosophical stance — it is a theorem. Any representation system that encodes rational numbers can be read under at least two fundamentally different, inequivalent metrics. The representation does not choose between them. There are exactly two choices to make, and the representation is neutral with respect to both.

## 2. Definitions

### 2.1 Absolute Value

An **absolute value** on a field $K$ is a function $|\cdot| : K \to \mathbb{R}_{\geq 0}$ satisfying:

1. **Positivity:** $|x| \geq 0$, and $|x| = 0$ if and only if $x = 0$.
2. **Multiplicativity:** $|xy| = |x|\,|y|$ for all $x, y \in K$.
3. **Triangle Inequality:** $|x + y| \leq |x| + |y|$ for all $x, y \in K$.

### 2.2 Archimedean vs. Non-Archimedean

An absolute value is called:

- **Archimedean** if the set $\{|n| : n \in \mathbb{Z}\}$ is unbounded. This means that integers can be arbitrarily large.
- **Non-Archimedean** (or **ultrametric**) if it satisfies the **strong triangle inequality**:

$$|x + y| \leq \max(|x|, |y|)$$

Equivalently, $|n| \leq 1$ for all integers $n \in \mathbb{Z}$.

### 2.3 Equivalence of Absolute Values

Two absolute values $|\cdot|_1$ and $|\cdot|_2$ on $K$ are **equivalent** if they define the same topology — that is, if $|x|_1 < 1 \iff |x|_2 < 1$ for all $x \in K$. Equivalently, there exists $\alpha > 0$ such that $|x|_2 = |x|_1^{\alpha}$ for all $x \in K$.

### 2.4 Examples

- **The real absolute value:** $|x|$ is the standard absolute value. This is Archimedean.
- **The $p$-adic absolute value:** For a prime $p$, $|x|_p = p^{-\nu_p(x)}$ where $\nu_p(x)$ is the $p$-adic valuation. This is non-Archimedean.
- **The trivial absolute value:** $|0| = 0$ and $|x| = 1$ for all $x \neq 0$. This is non-Archimedean but excluded from the theorem as "trivial."

## 3. Statement of Ostrowski's Theorem

**Theorem (Ostrowski, 1916):** Every nontrivial absolute value $|\cdot|$ on $\mathbb{Q}$ is equivalent to either:

1. The standard real absolute value $|\cdot|$, or
2. A $p$-adic absolute value $|\cdot|_p$ for some prime $p$.

These two families are mutually inequivalent: no $p$-adic absolute value is equivalent to the real absolute value, and no two $p$-adic absolute values for distinct primes are equivalent to each other.

**Corollary:** On $\mathbb{Q}$, there are exactly countably infinitely many inequivalent nontrivial absolute values: one Archimedean (the real absolute value) and one for each prime $p$ (the $p$-adic absolute values).

## 4. Proof Sketch

The proof proceeds by case analysis on the set of integer values $\{|n| : n \in \mathbb{Z}\}$.

### Case 1: There exists an integer $n > 1$ with $|n| > 1$.

Then the absolute value is Archimedean and is equivalent to the standard real absolute value.

**Argument:** Let $n_0$ be the smallest positive integer with $|n_0| > 1$. Define $\alpha > 0$ by $|n_0| = n_0^{\alpha}$. For any integer $m > 1$, expand $m$ in base $n_0$:

$$m = a_0 + a_1 n_0 + a_2 n_0^2 + \cdots + a_k n_0^k$$

where $0 \leq a_i < n_0$ and $a_k \neq 0$. Since $n_0^k \leq m < n_0^{k+1}$, we have $k \leq \frac{\log m}{\log n_0}$.

Apply the triangle inequality:

$$|m| \leq \sum_{i=0}^k |a_i| \cdot |n_0|^i \leq \sum_{i=0}^k n_0 \cdot n_0^{i\alpha} \quad (\text{since } |a_i| \leq a_i < n_0 \leq n_0^{\alpha} \text{ for } a_i < n_0)$$

After bounding the geometric series and taking roots in the limit, one obtains $|m| = m^{\alpha}$ for all integers $m$, hence $|x| = |x|^{\alpha}$ for all $x \in \mathbb{Q}$ — equivalence to the real absolute value.

### Case 2: $|n| \leq 1$ for all integers $n > 0$.

Then the absolute value is non-Archimedean. Since it is nontrivial, there exists some integer $n$ with $|n| < 1$. Let $p$ be the smallest positive integer with $|p| < 1$.

**Step 1:** $p$ must be prime. If $p = ab$ with $a, b < p$, then $|p| = |a| \cdot |b| = 1 \cdot 1 = 1$ (since $a, b < p$ implies $|a| = |b| = 1$ by minimality of $p$), contradicting $|p| < 1$.

**Step 2:** For any integer $n$, write $n = p^k \cdot m$ where $p \nmid m$. Then:

$$|n| = |p|^k \cdot |m| = |p|^k \quad (\text{since } |m| = 1 \text{ because } |m| \leq 1 \text{ and } m \text{ is not divisible by } p \text{ implies } |m| \not< 1)$$

Define $\alpha > 0$ by $|p| = p^{-\alpha}$. Then $|n| = p^{-\alpha \cdot \nu_p(n)} = |n|_p^{\alpha}$. By multiplicativity, this extends to all rationals: $|x| = |x|_p^{\alpha}$ — equivalence to the $p$-adic absolute value.

This completes the proof. $\square$

## 5. Implications for Metric Neutrality

### 5.1 The Theorem as a Constraint on Interpretation

Ostrowski's theorem tells us something profound about the structure of $\mathbb{Q}$: the field has exactly two kinds of "sizes" built into it. The real absolute value (magnitude) and the $p$-adic absolute values (divisibility) are the only possibilities. There is no third kind of metric.

For the metric-neutrality thesis, this means:

- **The Archimedean reading is not the "default" or "natural" reading.** It is one of two equally fundamental families.
- **The ultrametric reading is not exotic.** It is the other half of a complete classification.
- **Any representation of rational numbers is necessarily compatible with both readings.** There is no notation that encodes only the Archimedean valuation and excludes the $p$-adic valuations — because the field $\mathbb{Q}$ itself admits both.

### 5.2 The Duality Is at the Level of the Field, Not the Representation

This is the crucial point. The duality between Archimedean and non-Archimedean absolute values is a property of $\mathbb{Q}$ — it is built into the field axioms together with the requirement that an absolute value exist. It is not a choice made by any particular notation or representation system.

Ifrah's observation that number systems are "fossilized cognitive choices" takes on a new dimension: the cultures that developed these systems were making choices about *which* valuation to foreground (and they uniformly chose the Archimedean), but the field $\mathbb{Q}$ itself refuses to commit to that choice. The other valuations remain, latent, available to any reader who knows where to look.

### 5.3 The "Two Ways to Read the Same String" Is Not a Metaphor

The opening example of this project — the string $10$ read as Archimedean distance $10$ vs. $p$-adic distance $p^{-1}$ — might seem like a clever trick. Ostrowski's theorem shows it is not a trick. It is the manifestation, at the level of a specific symbol string, of a theorem about the structure of the rational numbers themselves.

The string $10$ represents the integer ten. The integer ten, as an element of $\mathbb{Q}$, has:

- Real absolute value: $|10| = 10$ (Archimedean)
- $2$-adic absolute value: $|10|_2 = 1/2$ (non-Archimedean)
- $5$-adic absolute value: $|10|_5 = 1/5$ (non-Archimedean)
- $|10|_p = 1$ for all other primes $p$

ALL of these are mathematically valid absolute values on $\mathbb{Q}$. The string $10$ does not — cannot — select among them. The selection is made by the interpretative framework applied by the reader.

### 5.4 QWAV and the Freedom to Choose

The QWAV framework's central move is to choose the ultrametric valuation over the Archimedean valuation for organizing quantum information. Ostrowski's theorem establishes that this is a *legitimate choice* — not a deviation from the "correct" mathematics, but a selection from the set of all possible valuations that $\mathbb{Q}$ itself admits.

One might even argue that the QWAV choice is more fundamental: the Archimedean valuation foregrounds magnitude (useful for commerce and measurement), while the ultrametric valuation foregrounds divisibility and hierarchical structure (useful for quantum information and error confinement). Different applications call for different valuations. The mathematics permits both. The metric-neutrality thesis simply makes this permission explicit.

## 6. The Complete Picture: $\mathbb{Q}$ as a Metric-Multiverse

Ostrowski's theorem reveals that $\mathbb{Q}$ is not a space with one metric. It is a space that admits a countable infinity of inequivalent metrics: one Archimedean and one for each prime. The real numbers $\mathbb{R}$ are the completion under the Archimedean metric. The $p$-adic numbers $\mathbb{Q}_p$ are the completions under the $p$-adic metrics.

The **adele ring** $\mathbb{A}_{\mathbb{Q}}$ is the restricted product of all these completions, providing a unified framework in which all valuations coexist. This suggests a deeper synthesis: perhaps the "true" object is not $\mathbb{R}$ or any single $\mathbb{Q}_p$, but the adelic whole — and our choice to foreground one completion over others is a pragmatic, context-dependent decision, not a reflection of ontological priority.

For metric neutrality, this means:

- Pre-numeric primitives encode relational data (correspondence, order, nesting) that is compatible with ALL completions.
- Positional notation adds grouping conventions (the base) but still does not select among completions.
- The field $\mathbb{Q}$ is the common substrate; the completions are "projections" obtained by applying different absolute values.
- There is no "true" metric — only a family of equally valid metrics, each appropriate for different purposes.

## 7. Summary

1. **Ostrowski's theorem** proves that every nontrivial absolute value on $\mathbb{Q}$ is equivalent to the real absolute value or a $p$-adic absolute value. There are exactly two families.

2. **For metric neutrality:** The theorem proves that the Archimedean reading is not the default — it is one of two equally fundamental options. The ultrametric reading is the other.

3. **The string $10$ example** is not a trick but the manifestation of Ostrowski's theorem at the level of a specific symbol: the same rational number admits multiple inequivalent absolute values, and the notation cannot choose among them.

4. **QWAV justification:** The choice of ultrametric valuation is mathematically legitimate. It is a selection from the valuations that $\mathbb{Q}$ itself admits, not a deviation from any "correct" reading.

5. **The deeper picture:** $\mathbb{Q}$ is a metric-multiverse. The Archimedean and $p$-adic completions are different projections from the same substrate. Metric neutrality is the recognition that no single projection has ontological priority.
