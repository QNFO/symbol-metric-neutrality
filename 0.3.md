# p-Adic Analysis Primer: Ultrametric Valuation

## 1. Motivation: The Same String, Two Metrics

Consider the symbol string $10$. In the conventional reading — positional notation, base $b = 10$ — this represents the quantity:

$$10 = 1 \cdot 10^1 + 0 \cdot 10^0 = 10$$

Under the real (Archimedean) absolute value, the distance of this number from zero is $|10| = 10$. But this is not the only possible reading. In a $p$-adic framework with $p = 10$ (or any prime dividing the "base" we choose to read under), the valuation of $10$ is entirely different. The $p$-adic valuation asks not "how large is the number?" but "how divisible is it by $p$?" — and the answer determines an ultrametric distance that behaves according to the strong triangle inequality rather than the familiar Archimedean one.

This primer develops the formal definitions needed to make these claims precise, and closes by connecting the mathematical framework to the metric-neutrality thesis: that pre-numeric primitives and positional notation carry relational data (order, correspondence, nesting) without committing to any particular valuation.

## 2. The $p$-adic Valuation

### 2.1 Definition

Let $p$ be a prime number. For any non-zero integer $x \in \mathbb{Z} \setminus \{0\}$, the **$p$-adic valuation** $\nu_p(x)$ is the highest exponent $n$ such that $p^n$ divides $x$:

$$\nu_p(x) = \max\{n \in \mathbb{N}_0 : p^n \mid x\}$$

Equivalently, $\nu_p(x)$ is the exponent of $p$ in the prime factorization of $x$. For rational numbers $x = a/b$ (in lowest terms), the valuation extends by:

$$\nu_p\left(\frac{a}{b}\right) = \nu_p(a) - \nu_p(b)$$

And by convention, $\nu_p(0) = \infty$.

### 2.2 Examples

- $\nu_2(8) = 3$ (since $8 = 2^3$)
- $\nu_2(12) = 2$ (since $12 = 2^2 \cdot 3$)
- $\nu_3(12) = 1$ (since $12 = 3 \cdot 4$)
- $\nu_5(12) = 0$ (since $5$ does not divide $12$)
- $\nu_{10}(100) = 2$ (since $100 = 10^2$)
- $\nu_2(1/8) = -3$

### 2.3 Key Property: The String $10$ Under Different $p$

The string $10$ — interpreted as the number "ten" — has prime factorization $10 = 2 \cdot 5$. Therefore:

$$\nu_2(10) = 1, \quad \nu_5(10) = 1, \quad \nu_p(10) = 0 \text{ for all other primes } p$$

But the crucial observation is: the valuation depends on which $p$ we choose to read the number under. The same integer, the same symbol string — different valuations depending on which prime we foreground.

## 3. The $p$-adic Absolute Value

### 3.1 Definition

The **$p$-adic absolute value** $|\cdot|_p$ is defined for $x \in \mathbb{Q}$ as:

$$|x|_p = \begin{cases} p^{-\nu_p(x)} & \text{if } x \neq 0 \\ 0 & \text{if } x = 0 \end{cases}$$

This is a non-Archimedean absolute value: numbers that are "highly divisible" by $p$ are $p$-adically small, and numbers that are "not divisible" by $p$ have size $1$.

### 3.2 Example: The String $10$ Revisited

$$|10|_2 = 2^{-\nu_2(10)} = 2^{-1} = \frac{1}{2}$$

$$|10|_5 = 5^{-\nu_5(10)} = 5^{-1} = \frac{1}{5}$$

$$|10|_{10} = 10^{-1} = \frac{1}{10} \quad \text{(if we extend to composite "base" valuation)}$$

Compare this to the real absolute value: $|10| = 10$. The same symbol string yields radically different "sizes" depending on the valuation framework — $10$ (Archimedean), $\frac{1}{2}$ ($2$-adic), $\frac{1}{5}$ ($5$-adic).

### 3.3 Properties of the $p$-adic Absolute Value

1. **Positivity:** $|x|_p \geq 0$, with equality iff $x = 0$
2. **Multiplicativity:** $|xy|_p = |x|_p |y|_p$
3. **Strong Triangle Inequality (ultrametric):** $|x + y|_p \leq \max(|x|_p, |y|_p)$

The third property is the defining feature of an ultrametric. It is stronger than the Archimedean triangle inequality $|x + y| \leq |x| + |y|$. In an ultrametric space, "all triangles are isosceles" — the two largest distances to any three points are always equal.

## 4. Ultrametric Distance

### 4.1 Definition

The $p$-adic distance between two numbers $x, y \in \mathbb{Q}$ is:

$$d_p(x, y) = |x - y|_p$$

This defines a metric on $\mathbb{Q}$. The completion of $\mathbb{Q}$ under this metric is the field $\mathbb{Q}_p$ of $p$-adic numbers.

### 4.2 Strong Triangle Inequality

The ultrametric property $d_p(x, z) \leq \max(d_p(x, y), d_p(y, z))$ has profound consequences:

- **Balls are clopen:** Every open ball is also closed, and vice versa.
- **All points in a ball are centers:** If $y$ is in $B(x, r)$, then $B(y, r) = B(x, r)$.
- **Overlapping balls are nested:** If two balls intersect, one is contained in the other.
- **The topology is totally disconnected:** No connected subsets larger than singletons.

These properties make $p$-adic spaces radically different from Euclidean spaces. They are hierarchical, tree-like, nested — properties that align naturally with hierarchical classification systems, ultrametric clustering, and the QWAV framework for ultrametric quantum computing.

### 4.3 Comparison: Archimedean vs. Non-Archimedean

| Property | Real (Archimedean) | $p$-adic (Non-Archimedean) |
|:---------|:-------------------|:---------------------------|
| Triangle inequality | $|x+y| \leq |x| + |y|$ | $|x+y|_p \leq \max(|x|_p, |y|_p)$ |
| Distance of $10$ from $0$ | $10$ | $p^{-1}$ (if $p \mid 10$) |
| Topology | Connected | Totally disconnected |
| Ball structure | Overlapping balls intersect | Overlapping balls are nested |
| Natural numbers | Increasing distance from $0$ | Bounded: all $|n|_p \leq 1$ |

## 5. From Positional Notation to Valuation

### 5.1 The $p$-adic Expansion

Every $p$-adic number $x \in \mathbb{Q}_p$ has a unique expansion:

$$x = \sum_{i = \nu_p(x)}^{\infty} a_i p^i$$

where each $a_i \in \{0, 1, \ldots, p-1\}$ and $a_{\nu_p(x)} \neq 0$ (unless $x = 0$).

This should look familiar — it is exactly the same form as a base-$p$ positional expansion, except that:
- The expansion can be infinite to the *left* (positive powers of $p$), not to the right
- The "first" non-zero digit determines the $p$-adic valuation

### 5.2 The String $10$ in $p$-adic Expansion

The string $10$, read as a base-$p$ expansion, represents:

$$10_p = 1 \cdot p^1 + 0 \cdot p^0 = p$$

Its $p$-adic valuation is $\nu_p(p) = 1$, and its $p$-adic absolute value is $|p|_p = p^{-1}$.

But the same string, read in a different base $q \neq p$, represents $q$, with different valuation properties. The string itself does not encode the valuation — the valuation is a function of the reading convention (which base, which prime, which metric).

### 5.3 General Principle

For any symbol string $d_n d_{n-1} \ldots d_1 d_0$ in positional notation with base $b$:

- The **real value** is $\sum_{i=0}^n d_i b^i$ — an Archimedean reading.
- The **$p$-adic valuation** (for a prime $p$) is $\min\{i : d_i \neq 0\}$, provided $p$ is compatible with the base in the appropriate sense. The $p$-adic absolute value is $p^{-\nu_p}$.

The string carries the digit sequence and its positional structure. The metric is supplied by the reader.

## 6. Connection to Metric Neutrality

### 6.1 Pre-Numeric Primitives as Valuation-Agnostic

A notch on a tally stick or a knot on a quipu says: "this is the $n$-th counted item." It encodes correspondence (one-to-one mapping to counted objects), order (the $n$-th comes after the $(n-1)$-th), and sometimes nesting (groups of groups).

What it does NOT encode is a valuation — a "distance" from the first item. If the valuation is Archimedean, the distance is $n$; if it is $p$-adic, the distance depends on the divisibility properties of $n$ by $p$. The tally stick doesn't choose. The mathematician does.

### 6.2 Positional Notation as Valuation-Partial

The positional string $d_n d_{n-1} \ldots d_0$ in base $b$ carries more structure than a tally — it carries grouping (the base) and weighting (powers of the base). But even this enriched structure does not fully determine the valuation:

- The real valuation reads the string as a magnitude: larger powers dominate.
- The $p$-adic valuation reads the string as a divisibility: the lowest non-zero digit determines "size."

Both readings are valid. Both are consistent with the positional structure. Neither is forced by the notation alone.

### 6.3 The QWAV Connection

The QWAV framework (Ultrametric Quantum Computing & AI) leverages the ultrametric property — the strong triangle inequality, the nested ball structure, the tree-like topology — as the foundation for error confinement, hierarchical information organization, and ultrametric coherence. The metric-neutrality thesis extends this framework to the anthropology of number representation: if ultrametric structure is a legitimate way to read number representations, then the QWAV project is not imposing a foreign structure on classical mathematics but recovering a reading that has always been latent in the notation.

## 7. Summary

1. The $p$-adic valuation $\nu_p(x)$ measures divisibility by $p$, not magnitude.
2. The $p$-adic absolute value $|x|_p = p^{-\nu_p(x)}$ makes numbers that are more divisible by $p$ *smaller*.
3. The $p$-adic distance $d_p(x, y) = |x - y|_p$ satisfies the strong triangle inequality (ultrametric property).
4. The same symbol string — whether a tally mark or the positional notation $10$ — can be read under either the Archimedean or the $p$-adic valuation. The metric is not carried by the symbol; it is imposed by the reader.
5. Pre-numeric primitives (notches, knots, beads) are valuation-agnostic: they carry correspondence, order, and nesting, and are compatible with any consistent valuation scheme.
