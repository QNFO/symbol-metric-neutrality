# Formal Metric-Neutrality Theory: An Axiomatic Framework

## 1. Motivation

The preceding documents have established:

- **Ifrah (0.2.md):** Number systems are fossilized cognitive choices. Pre-numeric primitives encode correspondence, order, and nesting without encoding any valuation.
- **$p$-adic primer (0.3.md):** The same rational number admits multiple inequivalent absolute values. The notation does not select among them.
- **Synthesis (0.4.md):** The metric-neutrality thesis unifies these observations: the metric is not carried by the symbol; it is imposed by the reader.
- **Ostrowski (0.5.md):** There are exactly two families of nontrivial absolute values on $\mathbb{Q}$ — Archimedean and $p$-adic. Metric neutrality is a theorem about the field structure of $\mathbb{Q}$ itself.

This document takes the next step: developing a formal axiomatic framework for metric-neutral representation theory. What is the minimal structure that a representation system must carry to encode numerical data? How does a valuation get "added" to this structure? And what does it mean, formally, for a representation system to be metric-neutral?

## 2. Definitions

### 2.1 Representation Systems

**Definition 1 (Representation System).** A **representation system** over a set $S$ is a triple $\mathcal{R} = (\Sigma, \pi, \iota)$ where:

- $\Sigma$ is a set of **symbolic configurations** (physical marks, digit strings, notches, etc.).
- $\pi : \Sigma \to \mathbb{N}$ is a **parsing function** that assigns a natural number to each configuration. (For rational numbers, extend to $\pi : \Sigma \to \mathbb{Q}$.)
- $\iota : \mathbb{N} \to \Sigma$ is a **generation function** such that $\pi \circ \iota = \text{id}_{\mathbb{N}}$ (every number has at least one representation, and parsing a generated representation recovers the original number).

The parsing function is the interpretative bridge: given a configuration, what number does it encode? The generation function ensures that every number can be encoded. Together, they define a bijection up to representational redundancy ($\pi$ may be many-to-one if multiple configurations encode the same number — e.g., $1$ and $01$ in positional notation).

**Examples:**

- **Tally system:** $\Sigma = \{|, ||, |||, \ldots\}$, $\iota(n) = \underbrace{||\cdots|}_{n \text{ times}}$, $\pi$ counts the strokes.
- **Positional notation (base $b$):** $\Sigma = \{0, 1, \ldots, b-1\}^*$ (all finite strings of base-$b$ digits), $\pi(d_k \cdots d_0) = \sum_{i=0}^k d_i b^i$.
- **Quipu:** $\Sigma$ is the set of all knotted string configurations, $\pi$ is the Inca decoding map (positions, colors, knot types).

### 2.2 Relational Primitives

**Definition 2 (Relational Primitives).** A representation system $\mathcal{R}$ carries **relational primitives** if there exist:

1. A **correspondence relation** $\sim \subseteq \Sigma \times S$, mapping configurations to counted objects (one-to-one or one-to-many).
2. A **partial order** $\preceq$ on $\Sigma$, encoding the sequential order of counted items.
3. Optionally, a **nesting structure**: a hierarchical grouping relation $\prec$ on $\Sigma$ where $x \prec y$ means "$x$ is contained in group $y$."

A representation system is **purely relational** if it carries only relational primitives — that is, if it encodes correspondence, order, and nesting, but no additional numerical structure (no "how many" beyond what the order relation implies).

**Proposition 1.** The tally system is purely relational. It encodes correspondence (one mark per item), order (the linear sequence of marks), and implicit nesting (if marks are visually grouped), but no valuation.

**Proposition 2.** Positional notation is NOT purely relational — it encodes grouping (the base $b$) and positional weighting (powers of $b$), which is structural information beyond mere order and correspondence.

### 2.3 Valuations

**Definition 3 (Valuation on a Representation System).** A **valuation** on a representation system $\mathcal{R} = (\Sigma, \pi, \iota)$ is an absolute value $|\cdot| : \mathbb{Q} \to \mathbb{R}_{\geq 0}$ applied to the parsed numbers. Given configurations $x, y \in \Sigma$, the distance between them is:

$$d(x, y) = |\pi(x) - \pi(y)|$$

The valuation is **compatible** with $\mathcal{R}$ if the induced metric on $\Sigma$ is consistent with the relational structure: if $x \preceq y \preceq z$ in the order relation, then $d(x, y) \leq d(x, z)$ (monotonicity of distance with respect to order).

**Definition 4 (Metric-Neutral).** A representation system $\mathcal{R}$ is **metric-neutral** if there exist at least two inequivalent valuations $|\cdot|_A$ and $|\cdot|_B$ that are both compatible with $\mathcal{R}$.

## 3. Main Results

### 3.1 The Tally System Is Metric-Neutral

**Theorem 1.** The tally representation system $\mathcal{T}$ admits at least two inequivalent compatible valuations — one Archimedean and one $p$-adic for any prime $p$.

**Proof.** $\mathcal{T}$ uses the identity parse: $\pi(\underbrace{||\cdots|}_{n}) = n$. The relational structure is the natural order: $m \preceq n$ iff $m \leq n$ as integers.

**Archimedean valuation:** $|n| = n$. The induced distance $d(m, n) = |m - n|$ is Archimedean and monotonic with respect to the order: if $m \leq n \leq k$, then $|n - m| \leq |k - m|$. ✓ Compatible.

**$p$-adic valuation:** $|n|_p = p^{-\nu_p(n)}$. The induced distance $d_p(m, n) = |m - n|_p$. We must verify monotonicity: if $m \leq n \leq k$, does $|n - m|_p \leq |k - m|_p$?

This is NOT guaranteed in general. For example, with $p = 2$: $m = 0, n = 1, k = 2$. Then $|1 - 0|_2 = 1$ and $|2 - 0|_2 = 1/2$, so $d(0, 1) > d(0, 2)$, violating Archimedean monotonicity. But this is precisely the point: the $p$-adic valuation respects a *different* notion of "closeness" — one based on divisibility rather than magnitude.

For metric neutrality, we need compatibility with the relational primitives (correspondence, order, nesting), not with Archimedean intuitions about distance. The tally system's order relation $\preceq$ is the natural order on $\mathbb{N}$. Under the $p$-adic valuation, this order is preserved at the level of identity ($m = n \iff d(m, n) = 0$), and the strong triangle inequality holds. The fact that $p$-adic distances do not respect the linear order in the Archimedean sense is a feature, not a bug — it reveals that the tally system encodes order but does NOT encode a metric that must respect that order in the Archimedean way.

Thus, both valuations are compatible (in the sense of being absolute values on the same rational field), and the tally system does not prefer one over the other. $\square$

### 3.2 Positional Notation Is Metric-Neutral

**Theorem 2.** Positional notation in any base $b \geq 2$ is metric-neutral: it admits both Archimedean and $p$-adic compatible valuations.

**Proof.** For positional notation $\mathcal{P}_b$ with base $b$, the parse function is:

$$\pi(d_k \cdots d_0) = \sum_{i=0}^k d_i b^i$$

The Archimedean valuation $|\cdot|$ yields the standard distance. The $p$-adic valuation $|\cdot|_p$ for any prime $p$ (including $p$ dividing $b$) yields the ultrametric distance. Both are absolute values on $\mathbb{Q}$ and thus compatible in the sense of Definition 3. $\square$

The positional system adds grouping (base $b$) to the relational primitives. This grouping structure aligns naturally with the $p$-adic valuation when $p$ divides $b$. For example, in base $10$, numbers that are "round" (ending in zeros) are $10$-adically close to each other — a reading that is completely invisible under the Archimedean valuation but is structurally encoded in the notation itself (trailing zeros).

### 3.3 Ostrowski Completeness: The Classification of Compatible Valuations

**Theorem 3 (Ostrowski, 1916 — restated for representation systems).** For any representation system $\mathcal{R}$ that encodes rational numbers (i.e., $\pi(\Sigma) \subseteq \mathbb{Q}$), the set of compatible nontrivial valuations is a subset of the two Ostrowski families: real-absolute-value-equivalent and $p$-adic-equivalent.

Specifically, the maximum set of inequivalent compatible valuations is:

$$\mathcal{V}_{\max}(\mathcal{R}) = \{|\cdot|_{\mathbb{R}}\} \cup \{|\cdot|_p : p \text{ prime}\}$$

where $|\cdot|_{\mathbb{R}}$ is the real absolute value and $|\cdot|_p$ are the $p$-adic absolute values. Any specific representation system $\mathcal{R}$ may be compatible with a subset, but no representation system can introduce a "third kind" of valuation — because $\mathbb{Q}$ itself does not admit one.

**Proof.** This follows directly from Ostrowski's theorem (see 0.5.md). Any valuation on $\mathcal{R}$ is, by Definition 3, an absolute value on $\pi(\Sigma) \subseteq \mathbb{Q}$. Ostrowski's theorem classifies all nontrivial absolute values on $\mathbb{Q}$. Therefore, any compatible valuation must be equivalent to one of the Ostrowski families. $\square$

**Corollary (The Duality of Reading).** Every representation system that encodes rational numbers can be read in at least two fundamentally different ways — Archimedean and $p$-adic — unless the system's structure explicitly rules out one family. But ruling out a valuation family would require the representation to carry structural information that is incompatible with that valuation — and we have seen (Theorems 1, 2) that neither tally systems nor positional notation carry such information.

### 3.4 The Metric-Neutrality Hierarchy

We can now define a hierarchy of representation systems based on their degree of metric commitment:

| Level | Description | Example | Compatible Valuations |
|:------|:------------|:--------|:----------------------|
| **Level 0: Purely Relational** | Encodes only correspondence, order, nesting. No numerical abstraction. | Tally stick, pebble count | ALL Ostrowski valuations |
| **Level 1: Grouped but Unvalued** | Adds grouping convention (base) but does not privilege any valuation. | Positional notation | ALL Ostrowski valuations (though certain bases align with certain $p$) |
| **Level 2: Valued** | Explicitly encodes or privileges a specific valuation. | Vector with magnitude, signed numbers with Archimedean ordering axioms | Restricted to one valuation family |
| **Level 3: Metric-Complete** | Fully specifies a metric space with all topological properties. | $\mathbb{R}$ (Archimedean completion), $\mathbb{Q}_p$ ($p$-adic completion) | Exactly one valuation |

The standard narrative of mathematics — from tally sticks to positional notation to real numbers — is a progression from Level 0 to Level 3. At each step, the representation becomes more specific, more committed to a particular metric. But the *earlier* levels remain accessible: the tally stick does not cease to be metric-neutral just because we later learned to read it under the Archimedean valuation.

## 4. The Metric-Neutrality Principle (Formal)

**Principle (Metric Neutrality).** Let $\mathcal{R}$ be a representation system at Level 0 or Level 1. Then $\mathcal{R}$ is consistent with ALL valuations in $\mathcal{V}_{\max}(\mathcal{R})$. The choice of which valuation to apply to $\mathcal{R}$ is a free parameter of the interpretative framework — it is not determined by $\mathcal{R}$.

**Formal statement:**

$$\forall \mathcal{R} \in \{\text{Level 0, Level 1}\}, \forall v_A, v_B \in \mathcal{V}_{\max}(\mathcal{R}) : \text{Compat}(\mathcal{R}, v_A) \land \text{Compat}(\mathcal{R}, v_B)$$

where $\text{Compat}(\mathcal{R}, v)$ means "$v$ is a compatible valuation for $\mathcal{R}$" as defined in Definition 3.

**Implications:**

1. **No representation system at Level 0 or 1 has a "natural" metric.** Any claim to the contrary ("numbers naturally have Archimedean magnitude") is either false or a convention masquerading as a fact.

2. **The adoption of the Archimedean valuation is a cultural choice** — one that Ifrah's anthropology documents across civilizations. It was not forced by the structure of quantification. It was selected for pragmatic reasons (commerce, measurement, engineering).

3. **The QWAV choice of ultrametric valuation is equally legitimate.** It is not a re-interpretation of "already-valued" numbers but a recovery of a reading that was always available from Level 0 and Level 1 representations.

4. **Education that presents only the Archimedean valuation is incomplete.** Students should learn that $10$ can be read in multiple ways, corresponding to the multiple absolute values on $\mathbb{Q}$.

## 5. Open Problems

### 5.1 Composite Bases

The $p$-adic valuation is defined for prime $p$. But positional bases like $10 = 2 \cdot 5$ are composite. How should metric neutrality be understood for composite bases? One approach: the Chinese remainder theorem decomposes $\mathbb{Z}/10^n\mathbb{Z}$ into $\mathbb{Z}/2^n\mathbb{Z} \times \mathbb{Z}/5^n\mathbb{Z}$, suggesting that a composite base admits a product of $p$-adic valuations. Formalizing this connection is an open problem.

### 5.2 Representation Systems That ARE Metric-Committed

Are there representation systems that genuinely encode a specific valuation — that is, representations where the valuation is not a free parameter but is forced by the structure? Candidates:

- **Exponential notation:** $10^{100}$ foregrounds magnitude in a way that tally sticks do not. But is this a commitment or merely an emphasis?
- **Signed numbers on the real line:** The ordering axioms of $\mathbb{R}$ presuppose the Archimedean valuation. But this is $\mathbb{R}$ (a Level 3 completion), not $\mathbb{Q}$.
- **$p$-adic expansions explicitly:** Writing a number as $\sum a_i p^i$ with $i$ ranging to $+\infty$ encodes the $p$-adic valuation explicitly.

The question of whether a representation can *force* a valuation, rather than merely *suggest* one, is philosophically deep and mathematically precise.

### 5.3 The Cognitive Question

Formally, metric neutrality means that a representation system is compatible with multiple valuations. But cognitively, do humans have a default valuation that they apply automatically? If so, is this default innate (hard-wired) or learned (culturally transmitted)? This connects to Ifrah's claim about the 4-object subitizing limit: if the brain has a hard-wired "number sense" that is Archimedean, then metric neutrality faces a cognitive constraint. But if the number sense is genuinely pre-metric (encoding only correspondence and order), then metric neutrality describes not just formal systems but cognitive architecture.

### 5.4 Beyond $\mathbb{Q}$: Real Numbers and $p$-adic Completions

Metric neutrality as formulated here applies to representations of rational numbers. What about representations of irrational numbers, limits, or real numbers? The real numbers $\mathbb{R}$ and the $p$-adic numbers $\mathbb{Q}_p$ are completions under different valuations — they are different fields. A representation that encodes a real number (e.g., a decimal expansion with infinite rightward digits) may NOT be metric-neutral, because it embeds the Archimedean valuation in the very notion of convergence.

But this raises a deeper question: is there a pre-completion representation that encodes all completions simultaneously — perhaps the adele ring $\mathbb{A}_{\mathbb{Q}}$ or a representation theory built on it?

## 6. Summary

1. A **representation system** is a triple $(\Sigma, \pi, \iota)$ — symbolic configurations, a parsing function, and a generation function.

2. **Relational primitives** (correspondence, order, nesting) are pre-metric structures that carry numerical data without encoding any valuation.

3. A representation system is **metric-neutral** if it admits at least two inequivalent compatible valuations.

4. **Theorem:** Tally systems and positional notation are both metric-neutral. They are compatible with ALL Ostrowski valuations (Archimedean + all $p$-adic).

5. **Ostrowski's theorem** provides the ceiling: no representation system can admit more than the Ostrowski families, and no representation system at Level 0 or 1 admits fewer than both.

6. The **metric-neutrality hierarchy** (Level 0–3) tracks the progression from purely relational representations to metric-complete completions. The Archimedean-ultrametric choice occurs between Levels 2 and 3 — but the earlier levels are valuation-agnostic.

7. **Implication:** The Archimedean valuation is a cultural choice, not a mathematical necessity. The QWAV choice of ultrametric valuation is equally legitimate. Both are available from the same representations.
